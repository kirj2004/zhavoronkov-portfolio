# Портфолио аналитика маркетплейсов

Аналитика юнит-экономики для продавцов Wildberries: считаю реальную
маржу по каждому SKU — с учётом комиссии площадки, логистики, возвратов,
штрафов и рекламы. Показываю, какие товары приносят прибыль, а какие
приносят только выручку.

Статический сайт на GitHub Pages. Без сборки и без бэкенда: HTML, CSS и
JS лежат в репозитории как есть, деплой — это просто публикация файлов.

### Как считается экономика

Все денежные значения в кейсах — из данных продавца, пересчитанные
по формуле юнит-экономики. Метод расчёта и его допущения описаны в
кейсах открыто: видно, что входит в себестоимость и что не входит.

Планируемые сценарии — например, «какая цена нужна, чтобы выйти в
плюс», — помечены отдельно и не выдаются за фактические продажи.

## Стек

- **HTML + CSS + JavaScript** — без фреймворков и без сборщика.
- **Chart.js** — графики на главной, в списке кейсов и в design system.
  Подключается с CDN только там, где графики есть.
- **lucide** — иконки, подключается с CDN на всех страницах.
- **Python** — служебные скрипты генерации страниц и проверок.
  В репозиторий не попадают: `.gitignore` исключает `*.py`.
  Скрипты восстанавливаются из истории или из своего каталога.

Никакой сборки: любой правки в файле достаточно, чтобы страница
изменилась.

## Запуск локально

```bash
python3 -m http.server 8899
```

Открыть <http://127.0.0.1:8899/>. Проверки страниц рассчитаны на этот
адрес и порт.

## Тема

Сайт тёмный: тема задана атрибутом `data-theme="dark"` в `<html>`.
Светлая тема тоже описана в CSS и проверяется в тестах, но переключателя
на страницах нет — тема фиксирована.

Токены тем и палитра — в `design-system/tokens.json`.
